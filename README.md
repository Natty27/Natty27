## About Me

I'm a full stack engineer focused on backend architecture. I like designing domain-driven systems, working close to the data layer, and shipping reliable, well-tested software.

- 🚚 Building **ChiNet TMS**, a multi-carrier Transport Management System on NestJS, MongoDB, Redis and Socket.io
- 🧩 Currently building its **HR module**: employee clearance, guarantees, item-loss records, injury reviews, training and employee self-service
- 🔐 Experienced with multi-tenant data isolation, role and policy-based access control, subscription-based feature gating, audit trails and i18n
- 🧪 Write layered tests (unit, integration, API and architecture tests) with Jest
- 📋 Plan and track work in Jira with ticket-driven development and design docs
- 🌍 Based in Ethiopia 🇪🇹
